## 🎯 Executive Philosophy: "The Luxury of Restraint"

The defining quality of Dr. Arefin's design system is **deliberate restraint**:
1. **Never use three shades when two will do**: Enforce a strict "Resting" vs. "Active" token pairing.
2. **Never cut backgrounds with opaque rectangles**: Use floating frosted islands (`bg-white/5` with `border-white/10`) so ambient curves pass through continuously.
3. **Never allow layout jitter**: Hovers modify illumination (brightness, border tint, sharp zero-blur shadow), **never position** (`translateY/X` forbidden).
4. **Anchor metrics in structured grids**: Numbers never wrap into arbitrary horizontal zigzags; they are vertically anchored within mathematically crisp cells (`gap-px`).
